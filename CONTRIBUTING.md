# Contributing to WaveAMP

**English** | [Русский](#участие-в-waveamp)

Thanks for your interest in WaveAMP!

WaveAMP is developed by its author; pull requests from outside contributors
aren't accepted. You can help with bug reports and ideas.

## Reporting bugs and suggesting features

Use [Issues](https://github.com/darkdkl/waveamp/issues) and pick the bug report
or feature request template. For bugs, include your WaveAMP version (Settings →
System → About), your OS and the steps to reproduce. Logs help a lot: enable
them in Settings → System → Logging, reproduce the problem and attach the file
from "Open logs folder".

Please report security vulnerabilities privately — see [SECURITY.md](SECURITY.md).

# Участие в WaveAMP

[English](#contributing-to-waveamp) | **Русский**

Спасибо за интерес к WaveAMP!

WaveAMP разрабатывает его автор; pull request'ы от сторонних участников не
принимаются. Помочь можно сообщениями об ошибках и идеями.

## Ошибки и предложения

Пишите в [Issues](https://github.com/darkdkl/waveamp/issues), выбрав шаблон
«ошибка» или «предложение». Для ошибок укажите версию WaveAMP (Настройки →
Системные → О программе), систему и шаги для воспроизведения. Очень помогают
логи: включите их в Настройки → Системные → Логирование, повторите проблему и
приложите файл из «Открыть папку с логами».

Об уязвимостях сообщайте закрыто — см. [SECURITY.md](SECURITY.md).
