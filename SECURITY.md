# Security policy

**English** | [Русский](#политика-безопасности)

## Supported versions

Security fixes go into the latest release only. WaveAMP updates itself
automatically; you can also check in Settings → System → Updates.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through GitHub: the
repository's **Security** tab → **Report a vulnerability**. Describe the issue,
the affected version and how to reproduce it. You'll get a reply as soon as
possible, and the fix will be released before the details are made public.

# Политика безопасности

[English](#security-policy) | **Русский**

## Поддерживаемые версии

Исправления безопасности выходят только для последнего релиза. WaveAMP
обновляется автоматически; проверить вручную можно в Настройки → Системные →
Обновления.

## Как сообщить об уязвимости

Пожалуйста, не создавайте публичный issue. Сообщите закрыто через GitHub:
вкладка **Security** репозитория → **Report a vulnerability**. Опишите проблему,
затронутую версию и как её воспроизвести. Ответ придёт как можно скорее, а
исправление выйдет раньше, чем подробности станут публичными.
