# Скины

[English](skins.md) | **Русский**

Скин меняет внешний вид WaveAMP: цвета, текстуры, кнопки-картинки, бегунки,
иконки и шрифт дисплея. Раскладка остаётся прежней: размеры, расположение и
пропорции плеера задаёт программа, поэтому любой скин работает с
эквалайзером, плейлистом, радио, аккордами, отдельными окнами и любым
масштабом интерфейса.

## Где лежат скины

В Настройки → Интерфейс → Скин перечислены встроенный скин и все скины из
папки скинов; кнопка **Открыть папку скинов** открывает её. Скин в этой папке —
это либо

- **папка** со `skin.json` и его файлами — удобно, пока скин делается;
- **файл `.waveskin`** — те же файлы, упакованные в zip, со `skin.json` в
  корне архива или внутри одной папки. Файл достаточно положить в папку
  скинов, распаковывать ничего не нужно.

Список следит за папкой сам. Пока скин выбран, сохранение любого его файла
сразу применяет изменения — плеер можно держать открытым рядом с редактором.
Если выбранный скин больше не читается — `skin.json` сломан или скин удалён, —
плеер переключается на встроенный скин; после исправления выберите скин снова.
При включённом логировании (Настройки → Системные → Логирование) причина
попадает в журнал.

Каждая папка и каждый `.waveskin` — отдельный скин, даже если у двух скинов
одинаковое название.

## Ползунки цвета

Скин задаёт основу, а ползунки в настройках подстраивают её поверх:

- при выборе скина ползунки встают на его `accent`, а **Сбросить**
  возвращает к нему;
- **Оттенок** и **Насыщенность** окрашивают дисплей и подсветку, в том числе
  включённых кнопок;
- **Цвет корпуса** подмешивает оттенок в цвета корпуса, кнопок, текста и
  бегунков из скина;
- картинки рисуются как есть — ползунки их не перекрашивают; иконки берут
  цвет кнопки, на которой стоят.

## skin.json

```json
{
  "format": 1,
  "name": "Carbon",
  "author": "Ваше имя",
  "version": "1.0",
  "accent": { "hue": 134, "saturation": 96, "tint": 0 },
  "colors": { "chrome": "#2a2e35", "button": "#363b43", "outline": "#000" },
  "effects": { "popupShadow": { "x": 0, "y": 6, "blur": 16, "color": "#00000066" } },
  "visualizer": { "peak": "#e06060" },
  "images": {
    "body": "img/body.png",
    "button": { "src": "img/button.png", "slice": 12, "width": 6 }
  },
  "icons": { "play": "icons/play.svg" },
  "fonts": { "display": "fonts/display.woff2" }
}
```

`format` должен быть `1`, `name` обязателен, остальное — по желанию. Всё, чего
нет в скине, берётся из встроенного скина, а незнакомые ключи пропускаются,
так что скин продолжит работать и в новых версиях WaveAMP.

| Ключ | Что значит |
|---|---|
| `name`, `author`, `version` | видны в списке скинов, до 60 символов каждое |
| `accent.hue` | 0–359, оттенок дисплея и подсветки |
| `accent.saturation` | 0–100 |
| `accent.tint` | 0–100, сколько оттенка подмешивается в корпус (ползунок «Цвет корпуса») |

### Значения

В скине только данные, CSS из них плеер собирает сам:

- **цвет** — строка в hex: `#rgb`, `#rrggbb` или с прозрачностью `#rgba` и
  `#rrggbbaa`, где `00` — прозрачный, `ff` — непрозрачный. Всё остальное,
  например `rgb()` или названия цветов, пропускается;
- **тень** — объект с `x`, `y`, `blur` и `spread` в пикселях и `color`,
  например `{ "x": 0, "y": 6, "blur": 16, "color": "#00000066" }`. Не
  указанное число считается `0`; `x`, `y` и `spread` — в пределах ±32, `blur`
  — от 0 до 64. `false` убирает тень. Внутренняя тень или внешняя, решает
  ключ;
- **градиент** (только `coverShade`) — список из 2–8 точек слева направо,
  `at` в процентах:
  `[{ "color": "#060a08d9", "at": 0 }, { "color": "#060a0873", "at": 100 }]`.

Значение, которое не подходит, пропускается, а при включённом логировании его
ключ попадает в журнал; остальная часть скина работает.

### effects

| Ключ | Где видно | По умолчанию |
|---|---|---|
| `knobShadow` | под бегунками и переключателями | `{ "y": 1, "blur": 2, "color": "#00000080" }` |
| `listInset` | внутренняя тень списков | `{ "y": 2, "blur": 6, "color": "#00000073" }` |
| `displayInset` | внутренняя тень дисплея и экрана аккордов | `{ "y": 2, "blur": 6, "color": "#00000099" }` |
| `popupShadow` | меню и форма станции | `{ "y": 6, "blur": 16, "color": "#00000066" }` |
| `pickerShadow` | открытые выпадающие списки | `{ "y": 10, "blur": 28, "color": "#00000099" }` |
| `coverShade` | градиент, приглушающий обложку на дисплее | `#060a08d9` на 0, `#060a08b3` на 55, `#060a0873` на 100 |

### visualizer

LED-спектр, стрелочные индикаторы и осциллограф. По умолчанию они берут цвета
дисплея.

| Ключ | Что значит |
|---|---|
| `foreground` | горящие сегменты спектра, стрелки, линия осциллографа |
| `dim` | шкалы индикаторов и их подписи L / R |
| `off` | погашенные сегменты спектра |
| `glow` | свечение вокруг горящих сегментов |
| `peak` | красная зона стрелочных индикаторов, выше 0 дБ |

### images

PNG, WebP, JPEG или SVG, до 2 МБ каждая. Путь указывается относительно
`skin.json` и не может выходить за пределы скина: без `..`, без абсолютных
путей, без `\`.

| Слот | Что это |
|---|---|
| `body` | текстура поверх корпуса, под всеми элементами |
| `display` | текстура поверх дисплея и экрана аккордов, под их текстом |
| `button` | лицевая сторона кнопок |
| `buttonHover` | кнопка под курсором (необязательно, иначе `button`) |
| `buttonPressed` | нажатая кнопка (необязательно) |
| `buttonOn` | включённая кнопка, например открытый эквалайзер (необязательно) |
| `knob` | бегунки, растягиваются до их размера (14 × 14 px) |

Картинка — это путь или объект:

| Поле | Что значит |
|---|---|
| `src` | путь |
| `repeat` | `true` — повторять плиткой, `false` — растянуть на всю площадь; текстуры по умолчанию повторяются |
| `slice` | для кнопок: ширина краёв в пикселях картинки. Углы сохраняют форму, края и середина растягиваются по размеру кнопки |
| `width` | для кнопок: ширина краёв на экране в пикселях; по умолчанию как `slice`. Для картинки, нарисованной в двойном размере, укажите половину `slice` |

Картинка кнопки заменяет собственный фон и рамку кнопки, поэтому рамку и
скруглённые углы рисуйте в самой картинке, а углы за скруглением оставляйте
прозрачными.

### icons

SVG или PNG, до 256 КБ каждая. Иконка — это форма: плеер берёт её контур
(альфа-канал) и закрашивает цветом кнопки, поэтому иконки следуют за
ползунками цвета и за подсветкой включённых кнопок. Рисуйте их одним цветом
на прозрачном фоне, квадратными, например 24 × 24.

| Слот | Кнопка |
|---|---|
| `previous`, `play`, `pause`, `stop`, `next` | управление воспроизведением |
| `volume` | динамик рядом с ползунком громкости |
| `eq`, `radio`, `playlist`, `chords` | кнопки разделов |
| `settings` | шестерёнка в заголовке |
| `reset` | сброс эквалайзера |
| `search` | поиск в плейлисте и радио |
| `folder` | «Добавить в плейлист» |
| `add` | «Добавить станцию» |
| `favorites`, `saved` | избранное и сохранённые названия в радио |
| `filter` | фильтры радио |
| `up`, `down` | предыдущее и следующее совпадение в поиске по плейлисту |
| `popout` | кнопка окна аккордов |
| `more` | меню сохранённых названий |

Кнопки, для которых в скине нет иконки, остаются со встроенной.

### fonts

| Слот | Где видно |
|---|---|
| `display` | часы, название и строка формата на дисплее, экран аккордов, цифры эквалайзера, поля поиска |

WOFF2, WOFF, TTF или OTF, до 2 МБ. Проверьте, что лицензия шрифта позволяет
распространять его в составе скина.

## Ограничения

- `skin.json` — до 64 КБ;
- все картинки, иконки и шрифты скина — до 8 МБ вместе;
- файл `.waveskin` — до 16 МБ и до 300 файлов.

Всё, что выходит за ограничения, пропускается (при включённом логировании — с
записью в журнал); остальная часть скина работает.

## Как собрать .waveskin

Сложите `skin.json` и папки, на которые он ссылается, в zip — в корень архива
или внутрь одной папки — и переименуйте архив в `название.waveskin`. Файлы
вроде `.DS_Store` и `__MACOSX` пропускаются.
